# Bugungu Heritage and Information Centre

The six approved standalone pages have been consolidated into one static Astro site.

## Pages

- `/` — Home
- `/heritage/` — Heritage
- `/about/` — About
- `/visit/` — Visit
- `/contact/` — Contact
- `/support/` — Support

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`. The deployable output is written to `dist/`.
